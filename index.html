      File No. 02 — Field reference
      
Keep the shapes straight

      
A quick reminder of the shapes and words from your paper notebook. Use these to plan the steps; no strict pseudocode grammar is enforced.

      

        
A / Flowchart symbols

        

          
          
Start / End
Oval — begin or stop the process.

        

        

          
          
Input / Output
Parallelogram — read a value or display a result.

        

        

          
          
Process
Rectangle — calculate or update a value, e.g. SET.

        

        

          
          
Decision
Diamond — ask a condition; choose Yes or No.

        

        

          
          
Flow arrow
Shows the direction of execution.

        

        

          
          
Connector
Continue the flow at a matching point elsewhere.

        

      

      

        
B / Pseudocode keywords

        

          
            
START / STOPBegin and finish the algorithm.

            
READ / INPUTTake a value from the user or problem.

            
PRINT / DISPLAY / OUTPUTShow the answer or a value.

            
SETCreate or change a value.

            
IFTest a condition; enter its Yes branch.

            
ELSE IF / ELSE / END IFAlternative branches and end of a decision.

            
WHILE / END WHILERepeat while a condition remains true.

            
FOR / END FORRepeat through a known range or collection.

            
RETURNGive a result back from a function.

            
THEN / AND / OR / NOTExpress condition branches and Boolean logic.

            
FROM / TO / STEPDescribe a loop's range and increment.

            
DO / REPEAT / UNTILWrite loop bodies or a repeat-until loop.

            
BREAK / CONTINUEExit a loop or skip to its next iteration.

            
FUNCTION / CALL / END FUNCTIONDeclare, invoke, and finish a function; use RETURN for its result.

            
ARRAY / LIST / STACK / QUEUEDescribe the data structure holding values.

            
PUSH / POP / PEEKIllustrate stack operations.

            
ENQUEUE / DEQUEUEIllustrate queue operations.

            
INSERT / DELETE / SWAPDescribe modifications to a data structure.

            
LENGTH / SIZE / INDEX / VISITReference size, location, or traversal actions.

          
        

      

      

        
C / Tiny worked example

        
START
READ n
SET sum = 0
FOR i FROM 1 TO n
  READ value
  SET sum = sum + value
END FOR
PRINT sum
STOP

        
The sequence is the idea. Later, write the equivalent Java solution in AlgoLab and step through it using your visualizer.
